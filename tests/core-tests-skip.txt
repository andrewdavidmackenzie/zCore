# ── Pager: COW fork through multi-level hidden nodes ──
# When a pager-backed page is COW-forked through nested hidden nodes,
# the root VMO allocates a zero frame instead of waiting for the pager
# to supply the actual content. The descendant copies zeros instead of
# the tagged pager data. Root cause: commit_page_internal on the pager
# root with WRITE from a descendant doesn't return SHOULD_WAIT when
# the page hasn't been supplied yet. Fixing this requires routing the
# pager request to the root VMO from the clone's page fault handler.
