# Fuchsia Zircon Prebuilt Binaries (x86_64)

Prebuilt binaries from the Fuchsia project for running Zircon core tests
against zCore on x86_64.

## Architecture

These are **x86_64 only**. CI jobs that use these binaries must run on
x86_64 runners. There are no aarch64 equivalents at this time.

## Contents

| File | Size | Description |
|------|------|-------------|
| `core-tests-standalone` | 15M | Zircon core syscall test suite (1,776 tests, 110 test cases) |
| `ld.so.1` | 889K | Fuchsia dynamic linker (from musl fork, uses only Zircon syscalls) |
| `libzircon.so` | 16K | Fuchsia vDSO -- syscall trampolines with correct syscall numbers |
| `libc.so` | 889K | Fuchsia C library (musl-based) |
| `libc++.so.2` | 1.1M | C++ standard library |
| `libc++abi.so.1` | 206K | C++ ABI support library |
| `libinspector.so` | 494K | Debug introspection (backtraces, registers, memory inspection) |
| `libmini-process.so` | 30K | Minimal child process helper for testing |
| `zx-syscall-numbers.h` | 14K | Generated syscall number definitions (205 syscalls) |

## Dependency chain

```
core-tests-standalone
  PT_INTERP: ld.so.1
  NEEDED: libmini-process.so, libinspector.so,
          libc++.so.2, libc++abi.so.1, libc.so, libzircon.so

ld.so.1 (dynamic linker)
  NEEDED: libzircon.so (only dependency)

libzircon.so (vDSO)
  Each exported function (e.g. _zx_channel_read) is a trampoline:
    mov syscall_num, register
    syscall / svc #0
    ret
```

Everything bottoms out at `libzircon.so` -> hardware trap -> kernel.

## Fuchsia source info

- **Fuchsia revision**: `7fec4d6b059`
- **Build product**: `bringup.x64`
- **Compilation mode**: `balanced`

### Build configuration (`args.gn`)

```gn
import("//boards/x64.gni")
import("//products/bringup.gni")

compilation_mode = "balanced"
rbe_mode = "off"
target_labels = [ "//zircon/system/utest/core:boot_tests" ]
```

### Fuchsia source locations for key libraries

| Library | Source path |
|---------|------------|
| `ld.so.1` + `libc.so` | `zircon/third_party/ulib/musl/` |
| `libzircon.so` | `zircon/system/ulib/zircon/` (assembly stubs) |
| `libinspector.so` | `zircon/system/ulib/inspector/` |
| `libmini-process.so` | `zircon/system/ulib/mini-process/` |
| `core-tests-standalone` | `zircon/system/utest/core/` |
| `zx-syscall-numbers.h` | Generated by `zither` from `zircon/vdso/*.fidl` |

## Validation baseline

On real Fuchsia/Zircon (QEMU x86_64, 4 CPUs, 8GB RAM):

- **1,776 tests** from 110 test cases
- **1,773 passed**
- **3 skipped**
- **0 failed**

## How to regenerate

On a machine with a Fuchsia checkout:

```bash
cd $FUCHSIA_DIR

# Configure bringup build with core tests
fx set bringup.x64 --args='compilation_mode="balanced"' \
  --args='rbe_mode="off"' \
  --args='target_labels=["//zircon/system/utest/core:boot_tests"]'

# Build (~50K steps, ~60 min on 12 cores)
fx build

# Collect artifacts
FOUT=out/bringup.x64-balanced
cp $FOUT/core-tests-standalone .
cp $FOUT/obj/src/zircon/lib/zircon/libzircon.so .
cp $FOUT/user.libc_x64/libc.so .
cp $FOUT/x64-shared/libmini-process.so .
cp $FOUT/x64-shared/libinspector.so .
cp $FOUT/obj/bundles/assembly/platform/platform_artifacts/fshost_common/compiled_packages/fshost/files/lib/ld.so.1 .
cp $FOUT/obj/bundles/assembly/platform/platform_artifacts/fshost_common/compiled_packages/fshost/files/lib/libc++.so.2 .
cp $FOUT/obj/bundles/assembly/platform/platform_artifacts/fshost_common/compiled_packages/fshost/files/lib/libc++abi.so.1 .
cp $FOUT/fidling/gen/zircon/vdso/zx/zither/kernel/lib/syscalls/zx-syscall-numbers.h .
```
